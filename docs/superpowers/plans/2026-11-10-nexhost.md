# NexHost Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A 4-year-plan-only NexHost page that hosts test sites from the user's own PC, with a file manager, a database per site, and Go live through the user's own Cloudflare or ngrok account; public links leave every other plan.

**Architecture:** The website adds `features` to plans and puts them in the signed license token; the app checks `license::require_feature("nexhost")` in Rust before any NexHost, Public link or Fixed link command. Sites live in `<root>\nexhost\<site>\`, get a web-server listener on `127.0.0.1:8201-8219`, and go live through the existing forwarder on port 8899, which grows into a router that picks the site by the visitor's `Host`.

**Tech Stack:** Website: Laravel 13, Inertia React, PHPUnit. App: Tauri 2, Rust (`app/src-tauri`), React + TypeScript (`app/src`).

**Spec:** `docs/superpowers/specs/2026-11-10-nexhost-design.md`

## Global Constraints

- Website repo `C:\laragon\www\nexdb`; app repo `C:\Users\PC\Documents\Reverse Eng` (app in `app/`).
- Website: every schema change is its own new migration. Prices in centavos. 4-year plan: `duration_days` 1460, direct `490000` (₱4,900), reseller `294000` placeholder, `features = ["nexhost"]`, active.
- Feature name string is exactly `nexhost`.
- Locked message (Rust and UI): `NexHost and public links are part of the 4-year plan.`
- NexHost site ports: `8201..=8219`, bound to `127.0.0.1` only, never added to the firewall rule.
- Router port: `fixedlink::FIXED_PORT` (8899). Cloudflare public hostnames point at `http://localhost:8899`.
- Site names: lowercase letters, digits, dashes, 1-40 chars, start with a letter or digit.
- Database and user name: `nh_` + site name with `-` replaced by `_`, cut to 32 chars total.
- MySQL only for site databases in this version.
- Plain language in every user-facing string (memory rule: no jargon; raw output only on request). Nielsen heuristics: status shown, errors say what to do.
- Web tests: NexDB PHP 8.4.27 with a scratch `PHPRC` ini (see project memory). App tests: `cargo test --lib` in `app/src-tauri`; UI: `npx tsc --noEmit` in `app/`.
- Single quotes, 4 spaces in PHP/TSX on the website; never run prettier with defaults.
- App version for this work: 0.5.5 (`tauri.conf.json`, `package.json`, `Cargo.toml`).

## Review Focus

1. File manager paths with `..`, absolute paths, or a zip entry like `../../evil.php` must never write outside the site folder (zip slip). Tests in Task 5.
2. A visitor's `Host` with a port or capitals (`Shop.MyShop.com:443`) must reach the right site; an unknown host gets the offline page, never another site. Test in Task 7.
3. License ends (Expired) or changes to a plan without `nexhost` while sites are live: every live site goes offline and the tunnel stops. Test in Task 8.
4. Dotfiles (`.env`, `.git`) inside the web root must return 403/404, and a Laravel site serves only `public/`. Test in Task 4.
5. Two sites whose names map to the same database name (`my-shop`, `my_shop` is invalid, but long names cut at 32 chars) must not share a database: creating the second one fails with a plain message. Test in Task 6.
